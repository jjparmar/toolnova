## Goal
Transform ToolNova into a cohesive, premium, professional-looking site across all pages — by **refining the existing token system and consolidating it into shared components applied everywhere**, rather than reinventing. Direction: **elevated confident-blue**, light-first with a fully token-driven dark mode.

## Root cause (why it doesn't feel premium today)
The design *system* is solid; the *application* is fragmented. There is no shared `ToolCard` (3+ inline variants), dead premium utility classes (`card-premium`/`btn-premium`/`bento-card` used 0 times), hardcoded off-token colors in several components, mixed corner radii, two icon libraries, and duplicate files. Fixing the system once and applying it uniformly is the whole win.

---

## PHASE 1 — Design-system foundation (do first, touches everything)

**1. Refine tokens in `src/app/globals.css`** (source of truth for Tailwind v4)
- Sharpen the blue scale: keep primary `221 83% 50%`, enrich gradient endpoints (deeper indigo `226→230`), add a refined cyan accent for glows. Tighten neutrals for a more "airy" premium light surface; deepen dark backgrounds slightly for depth.
- Unify radii: standardize cards on `--radius-lg` (`rounded-2xl`), buttons/inputs on `rounded-xl`, large feature containers on `rounded-3xl`. Remove ad-hoc mixing.
- Upgrade shadows into a layered "premium" scale (resting → hover → glow) so cards lift consistently.
- Revive + standardize premium utilities into one coherent set actually used everywhere: `.surface-card`, `.surface-glass`, `.surface-hero` (mesh/aurora), `.glow-ring`. Delete the dead ones (`btn-premium`, `bento-card`, `card-premium` as separate concepts) or fold them into the canonical classes.
- Add a reusable `.text-brand-gradient` for headline accents and a `.eyebrow` label style (used across every section header today).

**2. Fonts** — keep Manrope (body) + Sora (headings) + Geist Mono (already loaded via `next/font`). Tighten optical sizing & heading weight ramp (Sora 600/700 for display). No font swap needed — current choice is premium-appropriate.

**3. Create shared components** (`src/components/ui/` or `src/components/shared/`)
- **`ToolCard`** — the big one. A single component with a `variant` prop (`featured` | `grid` | `related` | `compact`) and a consistent visual language: gradient/glow icon tile, hover lift, accent top-bar, badge slot, consistent `rounded-2xl` + premium shadow. **Replaces the 3+ inline card implementations** in HomeDashboard, ToolsLibrary, RelatedTools, PremiumToolWrapper.
- **`SectionHeading`** — eyebrow (small uppercase primary label) + title + optional subtitle, centered or left. Used on ~every section today, hand-rolled each time.
- **`PremiumCard`** — base elevated surface (token-driven bg/border/shadow + hover lift) for why-us, trust, category cards.
- **`CategoryCard`** + **`CTASection`** (gradient + glow band replacing the flat `bg-primary` CTA).
- **`StatTile`** / **`Pill`** / **`IconTile`** small primitives to kill repeated inline markup.

**4. Standardize shadcn primitives** — refine `card.tsx` and `button.tsx` to use the new shadow/radius scale so even raw `Card`/`Button` usages look premium by default.

**5. Consistency cleanup**
- Migrate `ToolRichContent.tsx` from `react-icons/fa` → `lucide-react` (one icon lib).
- Replace off-token colors: `FAQAccordion` (`text-slate-*`→tokens), `RelatedTools` (`bg-[#f8f9fb]`→token), `ToolRichContent` (`bg-emerald-50`/`bg-white dark:bg-slate-900`→tokens).
- Consolidate duplicates: one `ThemeToggle` (delete Header's inline version), one `Breadcrumb` file.
- Dark-mode audit: ensure every new/changed class has correct `dark:` tokens so dark mode is fully token-driven (no hex overrides).
